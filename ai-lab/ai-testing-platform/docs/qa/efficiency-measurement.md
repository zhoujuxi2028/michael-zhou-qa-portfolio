# 用例生成提效 · 实测报告

> 目的：把「AI 用例生成提效」从口头数字变成**可复现、可推敲**的实测结论。
> 被测：`ai-lab/ai-testing-platform` 的 `TestCaseGenerator`（规则引擎）。
> 日期：2026-11-16。

## 1. 结论先行（区分「实测」与「假设」）

| 结论 | 类型 | 数值 |
|------|------|------|
| 引擎单次生成 8 条结构化用例耗时 | **实测**（N=50） | 中位 **≈0.4 ms**（多次运行 0.39–0.46；单次样例 min 0.27 / max 0.79 / std 0.10 ms） |
| CLI 端到端（含 Python 启动、读写文件） | **实测**（N=10） | 中位 **0.16 s** |
| 生成环节较人工提速 | **实测+边界推断**（对人工基线不敏感） | **> 99.9%**（见 §4，任意合理人工基线成立） |
| 端到端净提效（含人工复核） | **估算**（场景假设，非实测） | **约 50%–80%**（人工 2–5 min/条、复核 1 min/条，见 §5） |

> 一句话：**生成环节提速 >99.9% 是硬的**（引擎亚毫秒级，任何「分钟级」人工基线都成立）；**「净提效 67%」是场景估算**，随人工/复核假设在 50%–80% 间浮动，不可脱离假设单独引用。

## 2. 被测对象与输入

- 引擎：`src/case_generator/generator.py` → `TestCaseGenerator.generate_from_requirement`
- 输入：`docs/requirements/LOGIN-REQUIREMENTS.md`（固定用例，保证可复现）
- 产出：每次 8 条结构化用例（正向 1 / 负向 2 / 安全 2 / 边界 3），覆盖率评分 71.2

## 3. 测量方法

- 工具：`scripts/benchmark_case_generation.py`（`time.perf_counter`，先 warm-up 一次剔除首次导入成本）
- 迭代：引擎 N=50；CLI N=10（`/usr/bin/time -p`）
- 统计：min / median / mean / max / std / p95
- 原始数据：`docs/qa/case-generation-benchmark.json`
- 环境：macOS / Intel i5-1038NG7（8 线程）/ 16GB / Python 3.15.2

## 4. 生成环节提速（对人工基线不敏感 = 可推敲）

引擎中位约 0.4 ms，人工编写 8 条结构化用例（含前置条件/步骤/预期/优先级/类型）按不同假设：

| 人工假设 | 人工耗时 | 引擎(≈0.4ms)提速 | CLI(0.16s)提速 |
|---------|---------|-----------------|---------------|
| 1 min/条 | 8 min (480s) | 99.99992% | 99.967% |
| 2 min/条 | 16 min (960s) | 99.99996% | 99.983% |
| 3 min/条 | 24 min (1440s) | 99.99997% | 99.989% |
| 5 min/条 | 40 min (2400s) | 99.99998% | 99.993% |

**关键点**：引擎耗时相对任何「分钟级」人工基线都可忽略，因此「>99.9%」的结论**不依赖**具体人工取值——这才经得起追问（换任何合理假设结论不变）。

## 5. 端到端净提效（估算，必须带假设）

净提效 = (人工耗时 − 复核耗时 − 引擎耗时) / 人工耗时。固定复核 = 1 min/条（8 min）：

| 人工假设 | 净提效 |
|---------|-------|
| 2 min/条 (16 min) | **50%** |
| 3 min/条 (24 min) | **66.7%** |
| 5 min/条 (40 min) | **80%** |

若复核成本更高（如 2 min/条），净提效会降到 ~33% 甚至更低。

**因此**：对外只报区间 **「净提效约 50%–80%（人工 2–5 min/条、复核 1 min/条）」**，并注明**假设驱动、非实测复核时间**。不单独引用「67%」。

## 6. 局限

- 「人工编写耗时」「人工复核耗时」无法在 CI 客观复现，属经验假设；本报告用**区间 + 敏感性**兜底，而非单一数字。
- 本例为单一需求文档（登录），8 条用例；不同需求复杂度下用例数量与耗时会变。
- 引擎耗时是规则引擎（正则/模板），非 LLM；复杂/开放语义需求表现不同。

## 7. 复现命令

```bash
cd ai-lab/ai-testing-platform
python3 scripts/benchmark_case_generation.py --iterations 50   # 引擎 N=50
python3 scripts/generate_test_cases.py                          # CLI 端到端（可配合 time）
```

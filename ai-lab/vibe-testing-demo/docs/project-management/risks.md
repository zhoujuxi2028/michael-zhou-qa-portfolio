## RSK-VT-009 残余风险与边界

用户接受残余风险，因为被测应用只在本地、账号仅用于演示。生成与自愈在正常环境运行，不再以进程级隔离验证作为本 demo 的验收门禁。Copilot 工具授权只限制工具请求；Git 状态和 diff 只能事后发现部分仓库变化，不能阻止或检测 MCP 对仓库外文件和网络的访问，也不能证明进程隔离。不得读取真实凭据或敏感文件；若组织策略要求 sandbox，必须遵守，不得绕过。

历史探针和浏览器启动失败的实际结果保留在 [PoC-02](../poc/poc-02-copilot-playwright-mcp.md)，不代表 Playwright MCP、网络或凭据隔离通过。

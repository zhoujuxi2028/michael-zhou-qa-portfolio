## RSK-VT-009 自动执行放行条件

在真实 Copilot + Playwright MCP + 浏览器链路上，使用仅包含合成数据的专用环境，记录系统、CLI/MCP/浏览器版本、隔离配置及命令；分别验证允许访问目标页面与项目输出、拒绝读取及写入隔离外合成标记、拒绝访问合成凭据文件，以及仅允许完成任务必需的网络目标。每项保留可复核的正反例及退出状态，并确认模型服务的数据策略；用户审阅证据并批准后才可运行生成或自愈。无法验证、证据不完整或环境/配置/版本变化时，保持阻塞并重新验证。基础功能开发不要求调用 MCP。
